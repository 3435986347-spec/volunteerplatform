# 领域九 · 信息与公示（轮播 · 公告 · 文件 · 数据看板 · 数据汇总 · 投诉建议 · 全局搜索）

> **主要模块**：publicity（轮播、公告、文件）、data（看板、汇总、投诉建议）· **也涉及**：system（文件网盘与定时开放）、api / common（全局搜索）、activity（名单公示，见领域二）、各域的只读统计 service。
> 本页是**业务口径**；代码不变式见 [`模块/publicity.md`](../模块/publicity.md)、[`模块/data.md`](../模块/data.md)、[`模块/system.md`](../模块/system.md)。状态截至 2026-10-17。

## 现行规则

- **轮播图 / 公告**：后台增改删、排序、上下架；可跳转推文或小程序页；志愿者端只读已上架 / 已发布的（草稿不泄露）。
- **文件下载**：公示文件开关下载；需要「定时开放」的内置文件放在 system 的文件网盘里（公开到小程序、设开放时间与下载开关，**开放窗口按时间现算**），不往公示文件表同步。
- **数据看板**（首页 + 后台）：注册志愿者数、活动场次、志愿时长、参加人次、管理团队数、分队数等；每个指标的口径都调 owner 域的只读 service，data 不碰外域表。
- **数据汇总**（后台，Row 79 九块）：平台（含游客的用户人数）/ 社区帖子与违规 / 爱心企业商品、积分与评价 / 志愿小组与代报名 / 相册 / 举报、封号与处罚 / 微心愿 / 结对 / 捐书；**系统里不记的东西给 null 不给 0**（如相册视频数、查看下载人次）。「修建书屋数」＝收到过捐书物资的受赠单位数（XH45）。
- **投诉建议**：志愿者提交时**必选类别**，按类别进部门——活动类→组织部、协会内部类→秘书部、社区类→宣传部（XH28）；可带图片与问卷答卷（场景 5）。**工单在哪个部门手上哪个部门看**，转走就看不到；`data:complaint-all` 看全部、可代任何部门处理；只能转给有启用账号的部门。志愿者看到的进度只有提交 / 受理 / 流转 / 答复四步；答复发站内提示与短信。
- **全局搜索**：活动 + 公告 + 小组 + 分队合成一条信息流，跨块精确分页。
