# 领域一 · 用户与身份认证

> **主要模块**：auth（登录态、实名、PII、处置表与闸门、注销）· **也涉及**：user（资料、注销入口、恢复）、api（路由鉴权）、organization（RBAC、管理团队标记）、enterprise（企业账号）。
> 本页是**业务口径**；代码不变式与踩坑见 [`模块/auth.md`](../模块/auth.md)、[`模块/user.md`](../模块/user.md)、[`模块/api.md`](../模块/api.md)。状态截至 2026-10-17。

## 现行规则

- **五种身份**：游客（登录了没实名）→ 志愿者（身份证二要素实名）→ 活动临时负责人（考试通过，资格按时间现算，见领域五）/ 管理团队（`manager_flag=1`）；爱心企业是另一套账号（领域六）。游客升级为志愿者是**同一个账号原地升级**，不会并存两个号。
- **三套登录态互不通用**：志愿者 `/v`、后台 `/a`、企业 `/e` 各一套 token；路由白名单与「需登录」的划分在根文件「Sa-Token 路由鉴权白名单」表。
- **登录方式**：小程序默认手机号体系——验证码登录（陌生号自动建游客账号）、手机号 + 密码登录；微信 `jsCode2Session` 登录保留；开发登录 `/v/auth/login/dev` 只在 dev 打开，生产由 `ProductionConfigGuard` 拒启。
- **注册**：收姓名、身份证、手机号、政治面貌、学校、年级、地址、i志愿者码、头像；未成年人要紧急联系人（电话与本人不同）；要读协议并手写签名，记下所签协议版本；已用手机号登录的账号注册时手机号锁定为登录号。
- **实名核验**：腾讯云身份证二要素。返回码分流——服务侧故障 / 当日额度用尽抛「服务暂不可用」，**不说成核验失败**；格式非法的号本地先拦、不计费。
- **PII**：手机号、身份证 AES-GCM 密文 + HMAC 哈希；日志不打明文；按手机号找人一律走哈希。
- **账号状态**：正常 / 禁用 / 注销。**禁用的能登录，但只能看奖惩、提申诉**（XH10）；注销的登不上（冷静期内登录则撤销注销，XH25）。每个 `/v/**` 请求都重查一次状态，非正常即登出 403（禁用那一支除外）。
- **注销与恢复**：申请注销即退出登录，7 天冷静期内任何一种登录都撤销注销；到期完成注销，**手机号释放、身份证不能再注册**；本人想回来由理事会在后台恢复，填一个没被占用的号（XH23–XH25）。
- **处置（限制能力）**：三档——限制参加活动 / 限制发布社区（细分禁止发帖、评论、点赞、私信）/ 拒绝使用本程序；「是否生效」按时间现算，不靠定时任务改状态；「拒绝使用」蕴含其余各档（领域八「奖惩」开出，表在 auth）。
- **防滥用**：短信按「同号跨场景日限量 + 来源 IP 时 / 日限量」计数；验证码错满次数作废；后台登录账号锁定 + IP 喷洒上限。
