# 领域七 · 社区交流（帖子 · 互动 · 审核风控 · 举报禁言 · 私信）

> **主要模块**：social · **也涉及**：auth（处置闸门：限制发布社区及其细分）、enterprise（企业帖）、activity（相册同步到社区）、honor（主页勋章）。
> 本页是**业务口径**；代码不变式见 [`模块/social.md`](../模块/social.md)。状态截至 2026-10-17。

## 现行规则

- **四层门**：看帖要已验证手机号；发帖、评论、点赞、关注、私信要已实名；写入挂处置闸门（当前读 + 父行锁）；对方的隐私设置（禁关注 / 评论 / 点赞 / 私信、不让 TA 看、拉黑）。
- **帖子流**：最新 / 最热 / 关注 / 官方 + 搜索；最热＝Redis 小时桶（本小时 + 上一小时折算），Redis 不可用时退回按时间；**可见性只在一段 SQL 里定义**，帖子流、详情、主页都拼它。
- **帖子**：图文视频；图片只收本系统上传、视频走直传签名；可见性 4 档 + 禁止评论 / 点赞；作者可修改。官方帖由各部门在后台发、可回复评论，宣传部可删其他部门的。
- **审核与风控**：**先发后审**；串行 1–3 级审核、**同一人不能审同一帖的两级**；关键词命中**先藏后审**并插队；后台可隐藏、置顶、删除；后台看真实姓名与学校只给最高权限（`social:real-name`）。
- **举报与处罚**：举报由宣传部审、按对象结案；**社区处罚宣传部审核即生效**，用户照常申诉、申诉归理事会（XH11）。禁言即时生效、落在处置表：「限制发布社区」**蕴含**禁止发帖 / 评论 / 点赞；「禁止私信」是单独一档，只挡发不挡收。「封号」走账号禁用或奖惩。
- **互动通知**：赞 / 评论 / 回复 / 关注的互动列表（去重、可删、未读数）；每 20 分钟汇总一次落站内提示（微信订阅消息待模板）。
- **用户主页**：勋章、注册时间、发帖量、粉丝量、关注量、点赞量；隐私设置与备注。
- **私信**：会话 + 消息 + 未读已读；**清空只对自己**（后台记录一条不少）；对方可设禁止私信、拉黑即发不出；陌生人没回之前最多 3 条；关键词命中**不藏消息、另开插队工单**；聊天记录查看权 `social:chat-view` **默认不授任何人**。实时推送走 WebSocket `/ws/social/chat?token=`（先落库、提交后再推）。
- **企业帖**的作者 id 是企业 id，拿作者 id 查志愿者之前先看作者类型。
