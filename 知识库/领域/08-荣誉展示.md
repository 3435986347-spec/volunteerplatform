# 领域八 · 荣誉展示（排行榜 · 勋章 · 榜样 · 证书 · 奖惩）

> **主要模块**：honor · **也涉及**：activity（排行口径、违规、考勤确认事件）、donate（捐赠证书事件、微心愿排行）、auth（处置表与闸门、站内提示、通知短信）。
> 本页是**业务口径**；代码不变式见 [`模块/honor.md`](../模块/honor.md)。状态截至 2026-10-17。

## 现行规则

### 排行榜

- 活动次数 / 服务时长 / 积分 / 微心愿 × 月 / 年 / 总榜，可选历史月份。**当期实时聚合、往期读冻结快照**（历史名次不因事后补录而漂移）；出参 `fromSnapshot` 标明来源，总榜从不冻结。
- 快照由定时任务**每天**补齐（不是每月 1 日跑一次——漏跑就永久缺失），周期结束后留 7 天冷静期等确认与发放结算完；后台可显式补跑、强制重算。
- 口径只在 activity 的 `ActivityRankingQueryService`（微心愿在 donate）；积分榜排**累计获得**不是余额；微心愿按**已实现**数（XH44）。

### 勋章与榜样

- 勋章两条线：**样式审核**（长什么样、怎么拿到）与**发放审核**（这次授不授给这个人），只有过审的样式可发、只有过审的发放生效；改已启用的样式退回重审，志愿者端只读最后一次过审的版本。附带积分在生效那一刻入账。
- **全部由后台人工发放**（XH29），自动发放的取值保留未用。「我的勋章」带获取进度。
- 榜样：标题 / 副标题 / 简介 / 图片、个人或团队、跳转方式（无 / 小程序页面 / 备案网页 / 外部链接只能复制，出参同时给码值与英文名）、排序、上下架，新增先落下架态。志愿者端列表由**服务端**分页、按关键词（标题 / 副标题 / 简介）搜索、按个人 / 团队筛选、按运营排序或发布时间倒序（`GET /v/honor/role-models`）。

### 电子证书

- **活动证书**：秘书部确认考勤那一刻自动建（**一场次一张**，XH13），PDF 到首次预览 / 下载才渲染；只对上线后开展的活动自动发（XH14），其他由后台单传或批量上传（文件名内嵌手机号匹配）。事件丢失由补偿扫描兜底（有回看窗口，不碰历史）。
- **捐赠证书**：结对成功 / 心愿实现 / 捐物核对合格 / 众筹捐款到账时由 donate 事件触发（XH17），取消或退款即撤销。
- **公章在样本上**：把协会的盖章样本 PDF 当底图套印，**缺样本就拒绝出证**；样本两种——志愿活动（全局或按活动）与捐赠（XH16）。
- **先预览、再下载，只有下载计数**（XH15）；下载只发短期签名 URL（约 2 分钟）；证书可软删与恢复。小程序证书列表按「志愿活动 / 助学助困 / 微心愿 / 公益捐书 / 项目众筹」分页签。

### 奖惩中心

- 一张单装奖励与处罚。**处罚：组织部初审 → 理事会终审；奖励不经组织部、理事会审；持终审权的人开单即通过**（XH05、XH06）——判据是开单人的权限，不是请求里的开关。
- **五件效力全挂在终审那一刻**：置状态、定申诉截止（落库定死）、积分入账、施加处置、站内提示 + 短信。未终审前志愿者看不到。
- 申诉：只有处罚可申诉，**7 天**内，**由理事会受理**（XH07）；申诉成立写一笔反向积分流水、撤销处置。凭证图片只收本系统上传的。
- 一条违规至多一张有效单；**驳回或申诉成立后可再开一张「轻一点」的**，轻重由理事会人工把关（XH09）。开单与审核可以是同一人（XH08）。
- **处置三档按部门拆权限**：限制参加活动（组织部）、限制发布社区（宣传部）、拒绝使用本程序（秘书部），理事会三档都有（XH02）；开出与提前解除同一档要同一个权限点。
- 禁用账号照常可被开单审核，并能看奖惩、提申诉（XH10）。
