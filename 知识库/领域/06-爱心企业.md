## 现行规则

- **第三套登录态** `/e`：企业账号与志愿者、后台的 token 互不通用。注册要负责人手机验证码、统一社会信用代码（校验位）；后台审核通过 / 驳回，驳回后企业改资料重新提交；后台也可直接注册企业。
- **按账号状态放行**：已删除 / 已暂停的直接踢出 403；待审核 / 已驳回只放行登录相关、本企业资料、图片上传；正常的全放行。企业名称、信用代码、负责人**只在待审核或已驳回时可改**。
- **赞助商品**：企业自助发布走后台审核（与平台商品同一条线）、可隐藏 / 删除；后台可代发。**企业暂停或删除时，它的赞助商品同一事务里整批下架**，志愿者端不可见不可兑换。
- **企业核销员**：企业按手机号指定志愿者，只能核销本企业赞助的商品。
- **企业积分**是独立账本：赞助商品的兑换单领取后由补记任务入账（不挂在核销语句上）；后台调整带幂等键、扣减不为负。
- **企业帖**复用社区帖子，走同一条先发后审与关键词风控，作者名与头像取快照；⚠️ 企业帖的作者 id 是**企业 id**。
- **赞助商评价**：志愿者凭自己已领取的该企业赞助兑换单评价，一单一评；后台屏蔽 / 恢复 / 删除——**屏蔽 ≠ 删除**，屏蔽只对外藏、作者与后台仍看得到；企业能看收到的评价。
- **企业主页**（志愿者端）：编号、照片、名称、地址、电话、赞助商品、介绍、帖子、评价；只列状态正常的企业。
