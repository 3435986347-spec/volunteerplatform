# enterprise 模块 · 爱心企业

> 代码：`代码/hengde-volunteer-enterprise/`。本页由根 `CLAUDE.md` 的「已完成」表下沉而来（2026-10-17）；
> 上半部分是**现行要点**，下半部分是按批次的原始记录（为什么这样做、撞过什么）。两者冲突时以上半部分与代码为准，并顺手修正下半部分。

## 职责

企业账号（第三套登录态、审核、暂停）、赞助商品、企业积分账本、企业帖、赞助商评价。

## 现行要点

- `/e/**` 过 `EnterpriseAccountGate`：暂停 / 删除即踢出，待审核 / 驳回只放行资料与上传。
- 企业名称 / 信用代码 / 负责人只在待审核或驳回时可改，条件写在 UPDATE 的 WHERE 里。
- 企业暂停 / 删除在同一事务里整批置 `mall_goods.sponsor_suspended`；扣库存的 `UPDATE … JOIN` 带这个条件。
- 企业积分是独立账本，入账靠补记任务（不挂在核销语句上）。
- 赞助商评价资格只认兑换单，一单一评靠生成列唯一键；屏蔽 ≠ 删除。
