# user 模块 · 志愿者管理与个人中心

> 代码：`代码/hengde-volunteer-user/`。本页由根 `CLAUDE.md` 的「已完成」表下沉而来（2026-10-17）；
> 上半部分是**现行要点**，下半部分是按批次的原始记录（为什么这样做、撞过什么）。两者冲突时以上半部分与代码为准，并顺手修正下半部分。

## 职责

后台志愿者管理、志愿者端「我的资料」、地址、个人中心内容、手写签名板、订阅偏好、年级升级、志愿者证。

## 现行要点

- 后台按 id 的操作一律经 `requireRegisteredVolunteer`（游客行读写不了）；改实名资料只有超管（手写校验，不挂注解）。
- 全量 PUT 用 `LambdaUpdateWrapper` 显式 `.set()` 才能清空字段，并显式写 `update_time`。
- 换绑手机号：新号与原号都要验证码（没绑过号的第一次只验新号）。
- 跨域展示字段（时长、积分、小组、分队、职务）经各域只读 service 批量取，不直接查外域表。
- 年级按学年幂等升级（`grade_upgrade_year`），分界年级不替他升、挂提示。
- 志愿者证令牌是 24 字节随机数（不是 id），核验免登录、只给脱敏字段。
