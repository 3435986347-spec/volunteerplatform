# system 模块 · 系统治理

> 代码：`代码/hengde-volunteer-system/`。本页由根 `CLAUDE.md` 的「已完成」表下沉而来（2026-10-17）；
> 上半部分是**现行要点**，下半部分是按批次的原始记录（为什么这样做、撞过什么）。两者冲突时以上半部分与代码为准，并顺手修正下半部分。

## 职责

操作日志、界面水印、菜单排序、十位编号、文件网盘与分享。

## 现行要点

- 操作日志记 `/a/**` 的写操作 + 显式登记的敏感读；不记请求体；异步批量落库、绝不拖住业务；只追加。
- 水印文字由后端按当前账号算好再下发。
- 取号的两条语句必须在同一条连接上（包在事务里）。
- 网盘授权沿文件夹向下继承，只有超管能改授权；公开窗口按时间现算；分享令牌是随机数不是 id。

## 按批次的记录

**V4 系统治理批已完成（V83，2026-09-18）**：Row 62 日志记录 / Row 71 文件网盘 + Row 19 内置文件与定时开放 / Row 75 编号命名 / Row 77 菜单排序 / Row 78 界面水印。依赖 common / auth（**不依赖 publicity**：网盘文件不往 `publicity_file` 同步，见下）。**七张表**：`sys_operation_log`（只追加）/ `sys_config`（key-value，水印与菜单各一行 JSON）/ `sys_serial`（十位编号的段与流水）/ `sys_folder` / `sys_file` / `sys_folder_grant` / `sys_file_share`。**操作日志**（`OperationLogService` + api 的 `OperationLogInterceptor`，D9）：记 `/a/**` 的全部写操作 + **显式登记的敏感读**（各域导出、志愿者详情、聊天记录、到家名单、证书下载、分享被打开、以及「谁翻了日志」）——全记 GET 会把日志刷满、真要追的那几条反而找不到；**动作名取 Swagger 的 `@Operation(summary)`**（另维护一份动作名表必然与端点漂开）；**不记请求体**（改密码那类请求体里就是密码）；**失败也记**（被拒绝的越权尝试正是要追的）；

**异步批量落库、队列满了丢弃并 WARN、落库失败只记 ERROR**（日志绝不能把业务拖住）；**只追加**——没有删除入口，唯一的删除路径是保留期清理（Q8 默认 180 天，`SystemJobs`）。页面访问由前端上报 `POST /a/system/page-views`（后端看不见纯前端的路由切换），查看挂 `system:log`（**默认不授任何人**）。**水印**（Row 78）：**文字由后端按当前账号算好**（姓名 · 部门 · 手机尾号后四位 · 日期）——前端自己拼的话要先把手机号发到前端，为了防泄露先泄露一次说不通；关掉水印连文字都不下发。**菜单排序**（Row 77）整份覆盖、键重复直接拒。**十位编号**（Row 75，`SerialNumberService`）：`INSERT … ON DUPLICATE KEY UPDATE current_no = LAST_INSERT_ID(current_no + 1)` + `SELECT LAST_INSERT_ID()`，⚠️ **这两条必须在同一条连接上，所以包在事务里**——`LAST_INSERT_ID()` 是连接级的，不包事务时两条语句各借一条连接，16 个线程同时取号只取到 2 个不同的号（并发用例当场撞出来的）。只对 V4 新对象启用（Q12），存量编号不迁。**文件网盘**（Row 71，`FileVaultService`）：**授权沿文件夹往下继承**（授在上级对下级也算数，否则每建一个子文件夹都要重授一遍、漏授没有任何征兆），超管不看授权表、**只有超管能改授权**；**看不到的整枝在树里不出现**；删文件夹时有下级或有文件就拒绝（不连带删）；文件只收本系统传到 `vault/` 下的（`POST /a/files/upload?dir=vault`，**这个目录收文档**）。**公开到小程序**（Row 19）：`published` + 开放窗口**按时间现算**，不往 `publicity_file` 同步——同步就得靠定时任务把「到点开放」写成状态位，正是要避免的形状；志愿者端另开 `GET /v/system/files`，**关掉下载的只给名字不给地址**（只在前端隐藏按钮等于没挡）。**分享**：随机令牌不是 id、可设「要不要登录」与有效期，`GET /share/files/{token}` 是**公开路径**（与 `/callback/**` 同一机制落在鉴权处理器之外），下载计数那条 UPDATE 的影响行数是撤销之后的最后一道闸。3 个权限点 `system:log`
