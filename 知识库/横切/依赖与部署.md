# 依赖与部署

> 第三方依赖的版本钉子、webhook 的应答形状、线上排障。部署步骤本身在 `文档/v1/部署说明.md` 与 `部署/`（不进知识库：涉及线上环境细节）。
> 2026-10-17 从《约定与踩坑》按主题拆出；一条一节，先说规则、再说为什么 / 撞过什么。

## 线上「GET 就 500」先确认部署的是不是新包

**线上「GET 就 500」先确认部署的是不是新包（2026-10-08 小程序联调报告撞出）**：报告里 12 个接口在线上一律 500，查下来是服务器还跑着 09-17 之前的旧包——端点不存在，而旧版异常处理把「路径不存在」兜底成 500（`fe2fbc4` 才改成 404）。**不登录就能分辨新旧包**：`GET /api/actuator/info`（本批新开，只报 `build-info` 的版本 / 构建时间与 `SchemaVersionInfoContributor` 的迁移版本号，不含环境与连接信息）；旧包上它、`/share/files/x` 都是 500，`/v/user/volunteer-cards/verify` 要求登录。⚠️ 版本号没变时以 `build.time` 区分。**必跑用例 `GetEndpointSmokeApiTest`**：从 `RequestMappingHandlerMapping` 枚举全部 GET 端点，用未登录 / 游客 / 已实名且验过手机号 / 无权限子账号 / 超管 / 企业逐个打（路径变量填不存在的 id），断言零 5xx——新加的端点自动纳入，某个接口空数据时抛异常会精确报出路径与身份；另有三条部署探针。

## 第三方 webhook 的应答直接写 `HttpServletResponse`

**第三方 webhook 的应答不要返回 `String`（2026-09-17 撞出）**：`String` / `ResponseEntity<String>` 配 `application/json` 会被前置的 Jackson 转换器再序列化成一个 JSON 字符串（外面包一层引号、里面全转义），对方按报文判定成败时（快递100）会把每一次都当失败重推。**直接写 `HttpServletResponse`**（见 `TradeCallbackController.write` / `LogisticsCallbackController`），HTTP 用例要断言报文是 JSON 对象（以 `{` 开头），只断言「包含某个词」在引号包着时照样绿。

## Excel 依赖：POI 与 commons-compress、commons-io 配套

**Excel 导出依赖 POI 与 commons-compress 配套（2026-09-16 撞出的线上缺陷）**：此前打出的 `hengde-volunteer-api-2.0.1.jar` 里是 `poi-5.4.0` + `commons-compress-1.24.0`，POI 写 xlsx 时调用的 `ZipArchiveOutputStream.putArchiveEntry(ZipArchiveEntry)` 在 1.24 里不存在，**所有 Excel 导出**（志愿者名单、报名名单、捐赠物资明细）都以 `NoSuchMethodError` 失败，而构建与单元测试全绿——没有任何用例真的写出过一个 xlsx，是 `BookDonationApiFlowTest` 走 HTTP 真导出了一次才照出来。父 POM `dependencyManagement` 现把 `commons-compress` 钉在 1.27.1（POI 5.4.0 的 poi-ooxml 声明的就是它）；**升级 `poi.version` 时连同它一起改**，并跑那条用例。顺带：`ExcelUtil.export` 失败时先 `response.reset()` 再抛——否则全局异常处理器写不出 JSON，客户端拿到的是 HTTP 200 的残缺「xlsx」。⚠️ 已部署的 2.0.1 仍带着这个缺陷，**重新发版后要在生产实际导出一次**确认。 **读 xlsx 同理（2026-09-27 撞出）**：依赖调解给的是 `commons-io-2.14.0`，而 POI 5.4.0 读文件时调的 `BoundedInputStream.builder()` 在 2.14 里没有——**所有 Excel 导入**（微心愿批量导入、小组批量导入）都以 `NoSuchMethodError` 失败，对用户只显示「Excel 解析失败，请检查文件格式」，像是文件的问题。父 POM 已把 `commons-io` 钉在 2.18.0（POI 5.4.0 声明的版本），`AdminConsoleGapsApiTest.excelImportActuallyReadsAnXlsx` 真的写一个 xlsx 再走 HTTP 导入（去掉钉子必红）。**升级 `poi.version` 时 commons-compress 与 commons-io 两个钉子一起改**。

## 小程序验收脚本

`tools/miniprogram_acceptance.py`：`seed` 建小程序验收专用数据并写清单、`verify` 按小程序侧要求的格式出证据（时间 / 角色 / 对象 ID / 请求 / HTTP 与业务码 / traceId / 脱敏结果 / 是否符合期望）、`cleanup` 撤回；线上跑之前确认 `--base`。⚠️ 志愿者证核验的令牌等同于证件本身，证据里不记原文。
