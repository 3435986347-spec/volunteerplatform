## 自动加载

`代码/hengde-volunteer-*/CLAUDE.md` 各只有一行 `@../../知识库/模块/<模块>.md`：agent 改到某个模块时，Claude Code 会读入那个目录的 `CLAUDE.md`，
进而导入对应的模块页。⚠️ 只在完整工作区（`代码/` 位于本仓库之内）里路径成立；单独克隆后端仓库时这行导入找不到文件，需要另外放一份知识库。

## 维护

- 每批收尾：改所涉模块页的「现行要点」（只写现在是什么，一句一条），在「按批次的记录」末尾追加这一批；根 `CLAUDE.md` 只在规矩或路由变了时才改。
- 一条事实只写在一个页里，别处放链接；能从代码推出来的数字（权限点总数、迁移号、接口清单）以后改为脚本生成。
- 「现行要点」与「按批次的记录」冲突时，以现行要点和代码为准，并顺手修正记录里的那句。
